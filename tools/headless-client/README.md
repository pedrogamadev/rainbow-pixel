# tools/headless-client

Pasta reservada para o cliente sem interface, uma das ferramentas de teste da seção 17 do escopo da 1.0.

A implementação fica para o marco 0.2. Como toda ferramenta de teste, ela só poderá rodar com `DEV_TOOLS=true` e nunca com `NODE_ENV=production`. No marco 0.1 não há nada aqui além deste arquivo.
